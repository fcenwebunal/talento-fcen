# Talento FCEN

Plataforma de la Facultad de Ciencias Exactas y Naturales, Universidad Nacional de Colombia, Sede Manizales, para conectar a sus estudiantes y egresados recientes con empresas: perfiles con habilidades, búsqueda de talento, guía de prácticas para estudiantes y empresas, y administración de la Facultad.

Stack: Next.js y Supabase (Postgres, Auth, Storage).
